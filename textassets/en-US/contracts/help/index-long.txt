aoci index groups the index read commands. The index itself is written and maintained through the MCP tools aoci_maintain and aoci_update_entry.
inventory:      list files present on disk but absent from a Legacy index, with profiles; fully offline.
header show:    print the index Header, or the Meta dictionary of a Volumes layout; read-only.
score:          score a Legacy index across nine quality dimensions.
agent guide:    return the host-Agent workflow for the current repository state.
