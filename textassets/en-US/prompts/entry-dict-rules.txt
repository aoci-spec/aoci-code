Tag discipline (machine-enforced at Apply; any symbol outside the Header dictionary is rejected):
1. Every tag dimension must use a symbol already declared in the injected index Header. Never invent an undeclared symbol.
   For authoring, emit only the canonical compact A+B+C+[D]+E physical form, for example CG7T under the official starter Code dictionary. Dotted tags remain read compatibility for existing Legacy Entries; do not author new dotted tags.
2. Symbols in B Module and optional D Trait must not contain digits. The first digit in a compact tag is the boundary that begins C Importance.
   A common error is inserting the letter C for the C dimension into the B segment. If the B symbol is Srv, SrvC9 is wrong; Srv9 is correct. The C Importance digit follows the B symbol directly, without a C prefix.
3. Determine C Importance and E Scale from source size and responsibility under the Header rules.
4. If the Header has no suitable layer or module symbol for this file, do not force the nearest one. Append “Dictionary gap: consider adding symbol X” to S for maintainer review, while still using the most reasonable existing symbol in the Entry.
