Run entries stage and inspect the returned auto_finalize. On the normal path, do not call commands.check, commands.diff, or commands.apply separately.
When auto_finalize.status=applied, the current batch has completed Check, Diff, P-23, and atomic Apply. Run Verify and then guide again.
When auto_finalize.status=repair_required, read findings and correct only the failed Entries. Keep every other candidate unchanged, rewrite the same complete request file, and run commands.entries_stage again. Do not ask the user to reply “continue,” and do not call Entries Check, Diff, or Apply.
When auto_finalize.status=stopped, end that write attempt and inspect failed_step, error, formal-write evidence, and recovery. In auto mode, record a proven zero-write closure and obtain a fresh Plan; Resume a complete Intent with provable postimage; or complete a policy-selected Rollback with exact preimage and replan. Stop the user task only when proof is unavailable, third-party bytes conflict, bounded replanning cannot converge, approval or external action is required, or another safety boundary applies. Never bypass Generation Plan, P-23, CAS, or write-consistency safeguards.
A successful batch does not complete the full task. End only when guide returns complete, blocked, an approval stop, or a stopped result classified as user_action_required or hard_blocked. An ordinary response boundary, user question, repair_required, or auto-recoverable stopped attempt is not a completion condition.
