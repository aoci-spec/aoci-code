# Minimal AOCI Subject Repository

This tiny Go repository is an onboarding subject, not a benchmark result. Copy the directory outside the AOCI CLI checkout, initialize Git, and follow [`docs/getting-started.md`](../../docs/getting-started.md).

It intentionally contains no generated `aoci.txt` or `.aoci` state. `aoci init` must create the skeleton, and the active model must derive cognition from the source and test evidence.
