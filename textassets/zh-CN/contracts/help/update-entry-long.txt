不提供单条参数时，固定读取仓库根的 aoci.code.target.txt，绑定最终源码哈希并通过共享原子批次更新正式 Code 索引；成功后用正式 Code 同步 target，全程不调用模型。
提供 --path 后进入单条模式：对指定文件写入完整单行条目，已有条目整行替换，无则插入所属目录段。
条目使用共享的本地、Impact与S 字段Validator校验；--json下可修的Preview或Apply拒绝返回repair_required及与MCP相同的结构化Finding，只修retry_scope并保持其他候选不变。
正式写入必须用 --source-sha256 绑定 aoci_maintain 返回的源码指纹；内部复用原子批次、Baseline完整性与重放防线。
