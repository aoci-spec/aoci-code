# AOCI-CODE Public Runtime Contracts

This directory contains the contracts required to build, run, integrate, and
operate the public AOCI-CODE CLI and MCP server. Executable schemas, validators,
and `--help` output remain authoritative when a prose document is less specific.

## Contract map

| Surface | Contracts |
| --- | --- |
| CLI | `aoci-code-cli-runtime-v1.txt` |
| MCP | `aoci-mcp-runtime-v1.txt` |
| Configuration | `aoci-config-runtime-v1.txt` |
| Cognition format | `aoci-index-format-v1.txt`, `aoci-object-fras-v2.txt`, `s-field-discipline.txt` |
| Volumes and scope | `aoci-cognition-volumes-v1.txt`, `aoci-managed-scope-and-budget-v1.txt`, `aoci-safe-inventory-and-scope-refresh-v1.txt` |
| Database Evidence | `aoci-database-evidence-v1.txt`, `aoci-database-table-fras-v1.txt`, `aoci-database-cognition-authoring-v1.txt` |
| Host integration | `aoci-host-capability-and-interaction-v1.txt`, `aoci-host-cognition-messaging-v2.txt`, `aoci-overview-delivery-v1.txt`, `aoci-cognition-refresh-v1.txt`, `aoci-cognition-state-v2.txt` |
| Derived system cognition | `aoci-system-cognition-runtime-v1.txt` |

Planner derivation, patent material, commercial design, research records, and
experimental protocols are not part of this public contract set.
