Tag discipline (machine-enforced at Apply; any symbol outside the Header dictionary is rejected):
1. Every tag dimension must use a symbol already declared in the injected index Header. Never invent an undeclared symbol.
   For authoring, emit only the canonical compact A+B+C+[D]+E physical form, for example EG7T under the official starter Code dictionary. Dotted tags remain read compatibility for existing Legacy Entries; do not author new dotted tags.
2. Symbols in B Module and optional D Trait must not contain digits. The first digit in a compact tag is the boundary that begins C Importance.
   A common error is inserting the letter C for the C dimension into the B segment. If the B symbol is Srv, SrvC9 is wrong; Srv9 is correct. The C Importance digit follows the B symbol directly, without a C prefix.
3. Determine C Importance and E Scale from source size and responsibility under the Header rules.
4. Choose exactly one declared primary symbol for each tag dimension and prefer a specific named category when the evidence supports it. Under the official starter dictionaries, use G-CrossDomain only when the object genuinely spans domains and no single functional domain dominates. Use Z-Other only when the object is understood from sufficient evidence but the declared fixed dictionary does not otherwise cover it. For an existing or custom Header, follow its declared symbol meanings instead.
5. Insufficient evidence or failure to understand an object is not Z-Other: stop and report instead of hiding uncertainty in a tag. If no suitable symbol or Z-Other is declared, stop and report instead of inventing or forcing a symbol.
6. Classification uncertainty and dictionary-gap suggestions are governance concerns, not object constraints. Never put them in S; reserve S for qualifying non-inferable, error-preventing constraints from the object evidence.
7. Under the official starter dictionaries, a test file may use A=T, but its B Module should normally be the functional domain under test. Use B=Q only for test or quality infrastructure itself. For an existing or custom Header, apply the same distinction through its declared symbols.
